# 可复用 PYNQ 工程校验与排障技能包

本目录提炼本项目在配对 Overlay、DMA 和部署方面的经验。可用于其他 PYNQ 视频、采集和 AXI 控制项目，不依赖摔倒模型或 AC880 地址。

## 运行包一致性校验

使用 `python skill/overlay_bundle_check.py board_runtime`。也可对任意含相同 manifest.json 格式的目录运行。只需 Python 标准库，不连接开发板、不写寄存器。

校验器检查路径越界、大小与 SHA256、大小写冲突和缺失文件。它能发现复制遗漏、配对文件被替换等问题，不能证明地址映射正确、硬件行为正确或模型精度。清单本身必须来自可信构建。

本包使用当前 50 项静态运行文件完成正向测试，并使用临时目录中修改过内容的文件完成反向测试，均符合预期；记录见 sim/results/skill_check.json。

## DMA 与部署排障

参见 dma_debug.md，按资源所有权、帧完成、通道状态、冷启动和数据权限顺序排查。适用于具有 AXI DMA/VDMA 和共享内存的 PYNQ 系统；具体复位和缓存 API 必须按目标板与驱动确认。

## 来源与验证边界

- 从完整重建失败发现两个 Clocking Wizard 导出遗漏，补齐时钟脚本后完整构建通过。
- 从模式切换仍可能收到旧推理结果的风险提炼代次隔离和消抖测试，软件回归及 SW0 RTL 自检通过。
- FPGA 更新后一次热启动视频通道失败；重新上电后启动成功。根因未证实，不能把断电重启写成通用修复。
- root 复制数据导致日志重定向权限失败，恢复原 UID/GID 后继续启动。部署应校验数据所有权，不能只校验源码哈希。

这些经验是可复用的检查流程，不能替代新板卡的接口核对、独立场景验收或硬件时序签核。
